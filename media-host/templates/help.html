Setup & usage

Duplicates / best copy

The Duplicates tab (and the sibling Media Comparator on port 8767) groups the same title across drives and marks the highest-quality copy. It never deletes files. Deep scan of remote disks needs the 1.6 host installer (it puts ffprobe on the file host for you).

What this app does

  • Scans mounted paths on this catalog PC
  • Or scans local Windows disks via a small agent (no SMB share needed)
  • Media types: Movie, TV Show, MP3/FLAC (audio)
  • Video: .mkv .mp4 .m4v .avi .webm .mpg .mpeg
  • Audio: .mp3 .flac .m4a .aac .ogg .opus .wav (album folder used in title)
  • Skips junk folders (sample, proof, subs, …) and non-media files
  • Shows a clean title (folder name when it looks like a movie/show folder)
  • Tags per drive and per file (in a local SQLite DB — never renames files)
  • Exports a printable PDF list per drive

Media host (Windows or Linux)

The catalog PC cannot see unshared disks. Run the 1.6 installer on the machine that holds the files (Windows, Linux, or Mac). Same dark setup page as Media Comparator. Answer two questions, scan the LAN, then install. It installs Python if needed, ffprobe, CrystalDiskInfo (Windows) or smartctl (Linux), opens the firewall, and starts the agent.

  1. Download media-host-setup-1.6.zip
  2. Unzip on the media server.
  3. Windows: double-click INSTALL.bat. Linux/macOS: chmod +x INSTALL.sh && ./INSTALL.sh.
  4. Pick catalog vs file server and Windows vs Linux. Click Scan this network, then Suggest install.
  5. If this machine holds the disks, click Set up this host. Copy the address it shows.
  6. On the catalog PC: Add drive → media host → paste the address → List drives.

Inventory is stored on the catalog PC. Playback still happens on the media host. The installer opens the firewall for TCP 8766.

Mount Windows shares on Linux

Windows must share the folders first (Properties → Sharing, or Advanced Sharing).

# install tools once
sudo apt install cifs-utils

# create a mount point
sudo mkdir -p /mnt/win-movies

# mount (replace IP, share name, username)
sudo mount -t cifs //192.168.1.50/Movies /mnt/win-movies \
  -o username=YOUR_WINDOWS_USER,uid=$(id -u),gid=$(id -g),iocharset=utf8

# check it
ls /mnt/win-movies

Then in this app: Add drive → path /mnt/win-movies → Scan.

Persist mounts across reboot (optional)

# credentials file (mode 600)
sudo nano /etc/samba/win-creds
# username=...
# password=...

# /etc/fstab line example:
# //192.168.1.50/Movies /mnt/win-movies cifs credentials=/etc/samba/win-creds,uid=1000,gid=1000,iocharset=utf8 0 0

If a share is not visible from the catalog PC

  1. Prefer the media-host agent (above) — no sharing required.
  2. Or on Windows: share the folder; Private network; File and Printer Sharing allowed.
  3. From Linux: smbclient -L //192.168.x.x -U user to list shares, then mount and add as a local path.

Audio / music (MP3/FLAC)

Audio files are catalogued as type MP3/FLAC. Titles prefer Album — Track when the file sits in an album folder (Music/Artist/Album/01 Track.mp3). Re-scan drives after updating to pick up audio.

S.M.A.R.T. / disk health tags

Each catalogued drive can show a health badge and a drive tag: SMART:Healthy, SMART:Warning, SMART:Failing, or SMART:Unknown.

  • Windows agent drives — health comes from Windows Get-PhysicalDisk / Get-Disk / Get-Volume (and smartctl if installed on Windows). Agent version 1.1+ required for SMART.
  • Update the agent — Download agent pack (zip) on the catalog PC, copy to the file host, overwrite the old folder, restart run_agent.bat.
  • Local Linux mounts — uses smartctl (sudo apt install smartmontools). Network mounts have no local SMART.
  • Use Check SMART on a drive, or Check SMART all on the home page.

Unknown on some drives is normal: NAS mappings (e.g. Q:), some USB enclosures, RAID virtual disks, and subst paths often cannot expose SMART to Windows. Healthy/Warning/Failing on other letters still works when the OS can see the disk.

CrystalDiskInfo (recommended on Windows)

On the Windows file host we prefer CrystalDiskInfo (free) for SMART health. Install it, then restart the agent. The agent runs DiskInfo64.exe /CopyExit and reads DiskInfo.txt — it does not bundle CrystalDiskInfo; you install the official free app. 

# On Windows (optional but recommended)
winget install -e --id CrystalDewWorld.CrystalDiskInfo
# then restart run_agent.bat

Priority on Windows: CrystalDiskInfo → Windows Storage API → smartctl. Linux local mounts still use smartctl.

Bad sectors

When CrystalDiskInfo or smartctl can read the drive, the app also pulls sector-related counters:

  • Reallocated sectors — already remapped bad sectors (any > 0 is a warning)
  • Pending sectors — waiting to be remapped (any > 0 is serious)
  • Offline uncorrectable — unreadable sectors (any > 0 is serious)
  • UDMA CRC errors — often cable/USB dock noise, not always dying media
  • NVMe media errors — integrity errors on NVMe

This is not a full surface scan; it reads SMART attributes the drive reports. Install smartmontools on Windows for best results: winget install smartmontools (then restart the agent).

Data location

Catalog database: data/catalog.db next to the app. Safe to back up; deleting a drive in the UI only removes catalog rows, not media files.
