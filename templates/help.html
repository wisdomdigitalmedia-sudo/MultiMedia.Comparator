Sticky top rail on desktop (sliding active pill). Four-tab dock on phones. One content column, max 1180px.

Pool ring + per-drive free-space columns, plus used meters. Unknown volumes are listed, never drawn as 0%. Missing sizes are pulled from the media-host agent automatically.

Honest look
Premium local tool — not a SaaS marketing site. No fake activity, no invented capacity, no decorative 3D.

What this app does

  • Manages the same catalog.db as Media Catalog — add, scan, and remove drives here
  • Groups the same movie / episode / track across those drives
  • Scores every copy and marks one KEEP
  • Optionally deep-scans those copies with ffprobe / MediaInfo
  • Deletes a copy only after a two-step warning that shows the exact path twice

Grouping

  • Movies: normalized title + year (The Matrix 1999 ≠ Matrix Reloaded 2003)
  • TV: show + SxxExx (or air date for daily shows)
  • Audio: album + track
  • CD1/CD2 and serial chapters stay separate
  • Director’s Cut / Extended are flagged but still compared for quality

Score (best overall)

  1. Resolution (8K → 4K → 1080p → 720p → SD)
  2. Source (Remux > Blu-ray > WEB-DL > WEBRip > HDTV > DVD > CAM)
  3. Video codec (AV1 / VVC / HEVC / H.264 / MPEG-4 / …)
  4. HDR (Dolby Vision, HDR10+, HDR10)
  5. Audio (TrueHD Atmos, DTS-HD MA, FLAC, DD+, AC-3, AAC, MP3)
  6. File size vs expected bitrate for that resolution
  7. Container + whether a deep probe confirmed the streams

3D SBS/HOU copies are penalized for “best overall” (most libraries want the 2D master).

Codecs & containers scanned

Video: MKV, MK3D, MP4, M4V, MOV, AVI, WebM, MPG/MPEG, TS/M2TS, WMV, FLV, OGV, RMVB, 3GP, MXF, VOB, … Audio: FLAC, ALAC, WAV, AIFF, MP3, M4A, AAC, OGG, Opus, DTS, TrueHD, AC-3, E-AC-3, APE, WavPack, …

Deep scan

Deep scan needs ffprobe on the file host — this PC for local folders, the media-host PC for remote disks. The app installs it automatically if it is missing (portable build under tools/ffmpeg, or apt when passwordless sudo is available).

Remote disks need the Media Host installer 1.6 on the machine that holds the files (Windows, Linux, or Mac). Open Setup to answer two questions and scan the LAN, or download media-host-setup-1.6.zip and double-click INSTALL.bat / run INSTALL.sh. On Windows, firewall setup shows a Yes/No permission prompt (it may appear behind the browser) — click Yes. If that step still fails, double-click OPEN_FIREWALL.bat. 

python3 cli.py ensure-ffprobe

Supported layouts

  • Linux catalog + Windows file server
  • Linux catalog + Linux media server / NAS
  • Windows catalog + Windows file server
  • Windows catalog + Linux file server
  • Mac catalog + Windows or Linux file host
  • Everything on one computer (no agent)

Setup scans this subnet for ports 8766 (agent) and 8767 (Comparator) and fills in the address when it finds one.

Drives

Drives is the catalog. Add a remote volume through the media-host agent, or a folder mounted on this PC. Remove drops the volume from the catalog only — files on disk stay put. Size/free is read from the agent automatically.
